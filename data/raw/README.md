# Raw data — not committed

Everything in this directory is gitignored except this file. It contains identifiable
personal data and must never be committed, uploaded or shared.

## What belongs here

| File | Source |
|---|---|
| `RCT_DataLiteracy_DL_BK_July 20, 2026_10.55.csv` | Qualtrics export, main study |
| `RCT_DelayedRetest_PCP (rebuilt)_July 21, 2026_05.55.csv` | Qualtrics export, delayed retest |
| `participant_crosswalk.csv` | Generated by `deidentify.py` — maps Prolific ID → `P001`… |

## Why it is excluded

These files carry IP addresses, geolocation, Qualtrics recipient name/email fields and
Prolific IDs. Consent item 8 covers sharing **anonymised** data only.

`participant_crosswalk.csv` deserves separate mention: it is the single file that
reverses the pseudonymisation for every participant at once. Treat it as the most
sensitive artifact in the project. It is matched by its own `.gitignore` rule as well
as the directory rule, so it stays excluded even if moved.

## Getting the data here

The exports come from Qualtrics (**Data & Analysis** → **Export & Import** → **Export
Data** → CSV, "Use numeric values" **off**). Place them here with the exact filenames
above, or update `FILES` in `analysis/scripts/deidentify.py` to match.

Then:

```bash
python analysis/scripts/deidentify.py --derived
```

## If you are not the author

You do not need these files to reproduce the reported analysis — `data/public/` is
the complete export with identifiers removed, and every notebook runs against it.

Access to the raw data for verification purposes is by request to the author, subject
to the CUREC approval (reference `3366042`) governing the study.
