- Each **data point** becomes a **line**

- By following the line across the axes, you can see that item’s full profile

What they’re useful for:
- Comparing many variables at once
- Spotting **patterns**, **clusters**, **outliers**, and **relationships**
- Seeing whether high values on one variable tend to line up with high or low values on another

- They can get **messy** when there are lots of data points, because many lines overlap

-- USER T1: WHAT DOES A PARALLEL COORDINATES PLOT LOOK LIKE?
-- ASSISTANT T1: A **parallel coordinates plot** looks like a set of **vertical axes placed side by side**, with **lines running across them**.

### What you usually see
- **Several parallel vertical lines** — each line is one variable or category.
- **Data points shown as connected polylines** — each observation becomes a line that crosses every axis at its value.
- The line **moves left to right** across the axes, connecting values for the same item.

### Simple mental picture
Imagine:

- Axis 1 = Height
- Axis 2 = Weight
- Axis 3 = Age

One person’s data would be a **single zigzagging line** connecting their value on Height, then Weight, then Age.

### Key visual features
- **Many overlapping lines** if there are lots of observations
- **Crossing lines** can show differences between patterns
- **Clusters of similar lines** can suggest similar groups

### In short
It looks like **multiple upright scales in a row, with lots of slanted lines connecting them across the chart**.
